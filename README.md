### Projets

#### 🏛️ [ESB Hub](https://github.com/nadhirXt/Esbsite-) · [esbhub.study](https://esbhub.study)
En arrivant en première année à l'ESB, les cours, les annales et les mémoires étaient dispersés et difficiles à trouver pour les nouveaux étudiants.

J'ai développé une plateforme web centralisée pour regrouper toutes les ressources pédagogiques de l'école (cours, mémoires de stage, documents administratifs) et faciliter le travail des promotions suivantes.

- **Stack** : Next.js 16, TypeScript, Supabase (PostgreSQL, Auth), Backblaze B2 (stockage S3), Tailwind CSS.
- **Lien** : [Code source sur GitHub](https://github.com/nadhirXt/Esbsite-) · [Plateforme en ligne](https://esbhub.study)

---

#### 📧 Automatisation des cours : Gmail → Google Drive & Telegram
En tant que délégué de ma promotion à l'ESB, je recevais tous les cours des professeurs par email. Devoir télécharger manuellement chaque fichier, le classer dans le bon dossier du Drive partagé, puis rédiger un message sur notre canal Telegram prenait beaucoup trop de temps à chaque envoi.

J'ai mis en place un pipeline n8n qui tourne en continu : dès qu'un email de cours arrive, le workflow extrait les pièces jointes, les range au bon endroit sur Google Drive et publie automatiquement l'annonce avec le lien sur le canal Telegram de la promotion.

- **Stack** : n8n, API Gmail, API Google Drive, API Telegram Bot.

---

#### ⚡ [daily-news-n8n-bot](https://github.com/nadhirXt/daily-news-n8n-bot)
Pour faire ma veille économique et financière chaque matin sans y passer deux heures, j'avais besoin d'un résumé fiable des annonces des banques centrales (BCE, Fed) et des marchés. Les résumés faits par les IA classiques inventent souvent des chiffres ou des liens qui n'existent pas.

J'ai construit un bot n8n autonome qui récupère 16 flux RSS officiels, synthétise l'essentiel avec Gemini 3.8 Flash et vérifie mot pour mot chaque phrase et chaque chiffre dans le texte source avant de m'envoyer le briefing sur Telegram.

- **Stack** : n8n, Google Gemini 3.8 Flash, Docker, API Telegram.
- **Lien** : [Code source sur GitHub](https://github.com/nadhirXt/daily-news-n8n-bot)
